# Бэкенд «Арвари»

API вики: статьи, вестники, хронология, предложка, загрузка картинок.
ASP.NET Core (C#, .NET 10) + SQLite. Ручки описаны в [`../docs/API.md`](../docs/API.md).

## Запуск

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

```bash
cd backend
dotnet run --urls http://localhost:5174
```

При первом запуске создаётся база `arvari.db` и в неё засевается хронология
(`Seed/chronology.json`). Статьи, вестники и предложения стартуют пустыми.

## Настройки (переменные окружения)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `ARVARI_PASSPHRASE` | слово-ключ входа Мастера | `арвари` (только для разработки!) |
| `ARVARI_SECRET` | секрет подписи токена | случайный на каждый запуск |

Для боевого запуска **обязательно** задайте свои `ARVARI_PASSPHRASE` и
устойчивый `ARVARI_SECRET` (иначе токены сбрасываются при перезапуске).

## Связка с фронтендом

Фронт общается с API через `VITE_API_URL`. Локально:

```bash
# в корне проекта — .env.local
VITE_API_URL=http://localhost:5174
```

Пусто — фронт работает без бэкенда, на localStorage (мок-режим).

## Данные

- `arvari.db` — база SQLite (в `.gitignore`, не коммитится)
- `uploads/` — загруженные картинки (в `.gitignore`)
- `Seed/chronology.json` — стартовая хронология

## Что учесть при развёртывании

- CORS сейчас разрешает `localhost:5173/4173` — добавьте боевой домен фронта
  в `Program.cs`.
- Загруженные картинки лежат на диске сервера рядом с базой — при переезде
  переносите папку `uploads/` вместе с `arvari.db`.
- SQLite подходит для одного Мастера и умеренной нагрузки. Под рост — миграция
  на PostgreSQL (EF Core меняет только строку подключения и провайдер).
