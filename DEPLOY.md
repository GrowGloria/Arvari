# Развёртывание «Арвари» на своём сервере

Сайт (фронт + бэк + база) работает **одним приложением** в Docker. Наружу его
выпускает **Cloudflare Tunnel** — без проброса портов на роутере и с бесплатным
https. Всё живёт на вашем мини-ПК; абонплаты нет.

Порядок: подготовить сервер → поставить Docker → взять код → сделать туннель →
запустить. Дальше — по шагам. Команды выполняются **на мини-ПК**.

---

## Что понадобится

- Мини-ПК с **Ubuntu Server** (LTS), подключён кабелем к роутеру, включён 24/7.
- Бесплатный аккаунт **Cloudflare** и **домен**, добавленный в Cloudflare
  (домен ~1–2 $/год на распродажах; без домена публичной ссылки не будет).

---

## Шаг 1. Docker на Ubuntu

```bash
sudo apt update && sudo apt install -y docker.io docker-compose-plugin git
sudo usermod -aG docker $USER   # чтобы docker работал без sudo
# выйдите и зайдите заново (или перезагрузитесь), чтобы группа применилась
```

Проверка: `docker run hello-world` — должно вывести приветствие.

## Шаг 2. Код

```bash
git clone https://github.com/GrowGloria/Arvari.git
cd Arvari
git checkout frontend          # пока работа в этой ветке (или main, если влили)
```

## Шаг 3. Cloudflare Tunnel

1. Зайдите на **one.dash.cloudflare.com** (Zero Trust) → **Networks → Tunnels →
   Create a tunnel** → тип **Cloudflared** → задайте имя (например `arvari`).
2. Cloudflare покажет команду с **токеном** (длинная строка после `--token`).
   Скопируйте **только токен** — он нужен на шаге 4.
3. На вкладке **Public Hostname** добавьте запись:
   - **Subdomain**: например `wiki` (получится `wiki.вашдомен`),
   - **Domain**: ваш домен,
   - **Service**: тип `HTTP`, адрес `app:8080`.
   Сохраните.

## Шаг 4. Секреты

```bash
cp deploy/.env.example .env
nano .env
```

Заполните:
- `ARVARI_PASSPHRASE` — своё слово-ключ для входа Мастера.
- `ARVARI_SECRET` — длинная случайная строка. Сгенерировать: `openssl rand -hex 32`.
- `CLOUDFLARE_TUNNEL_TOKEN` — токен из шага 3.

Сохраните (Ctrl+O, Enter, Ctrl+X).

## Шаг 5. Запуск

```bash
docker compose up -d --build
```

Первая сборка идёт несколько минут (качает образы, собирает фронт и бэк).
Проверка на самом сервере: `curl -s localhost:8080/api/chronology` — вернётся JSON.

Готово: откройте `https://wiki.вашдомен` с телефона — сайт работает из интернета.

## Дальше

- **Вход Мастера**: `/editor`, слово-ключ из `ARVARI_PASSPHRASE`.
- **Данные** (база + картинки) лежат в docker-томе `arvari-data` и переживают
  перезапуск и пересборку. Бэкап — скопировать этот том.
- **Обновить сайт** после изменений в коде:
  ```bash
  git pull
  docker compose up -d --build
  ```
- **Логи**: `docker compose logs -f app` (или `cloudflared`).
- **Остановить**: `docker compose down` (данные сохранятся). Полностью стереть
  данные: `docker compose down -v`.

## Заметки

- Мини-ПК должен быть включён — выключили, сайт недоступен.
- Домен нужен именно на Cloudflare (там же настраивается туннель). Если домена
  нет — можно временно поднять быстрый туннель `cloudflared tunnel --url`, но
  адрес будет случайным и меняться при каждом перезапуске (для постоянного
  сайта не годится).
- SQLite тянет одного Мастера и умеренный трафик. Под серьёзный рост — переезд
  на PostgreSQL (в бэкенде меняется провайдер и строка подключения).
- Пакетно залить статьи из Obsidian: `node scripts/import-obsidian.mjs "<папка>"
  "Файл1" …` (см. комментарий в скрипте).
